# XPay Labs SDK Vue 3 示例

[English](README.md) | 中文

本项目演示了如何在 Vue 3 应用中集成 XPay Labs 加密货币支付网关 SDK。

## 功能特性

- 使用 API 凭证初始化 XPay Labs SDK
- 创建加密货币收款订单
- 显示支付二维码
- 查询支付状态
- 获取支持的加密货币和链
- 验证 Webhook 签名

## 安装

```bash
npm install
```

## 运行

```bash
npm run dev
```

浏览器访问 http://localhost:3000
